## How to Run the Activities

1. Install [Node.js](https://nodejs.org/).
2. Clone this repository:

```bash
git clone https://github.com/Mattzacarias/ELEC3-Nodejs-Zacarias.git
```

3. Open the repository folder:

```bash
cd ELEC3-Nodejs-Zacarias
```

4. Switch to the branch containing the activity you want to run.

For Set 1:

```bash
git switch set-1
```

For Set 2:

```bash
git switch set-2
```

5. Open the activity folder and install dependencies if required:

```bash
npm install
```

6. Run the activity using the appropriate command, such as:

```bash
node index.js
```

**Note:** Some activities may have their own specific instructions or npm scripts. Check the activity folder for its README or `package.json`.
